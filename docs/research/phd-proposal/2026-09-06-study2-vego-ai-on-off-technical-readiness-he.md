# דוח מוכנות טכנית — מחקר 2A (VEGO-AI_ON / VEGO-AI_OFF)

**תאריך:** 6 בספטמבר 2026 · **מצב:** `READY_FOR_SEPARATE_RUN_AUTHORIZATION` להכנה בלבד; לא בוצעה הרצה מדעית.

## תקציר מנהלים

החבילה הטכנית של מחקר 2A מוכנה לבחינה נפרדת: קיימות שתי קונפיגורציות מפורשות, סכימת JSON, מאמת שוויון, מזהי תנאי וריצה דטרמיניסטיים, מדיניות פרטיות, שער מחזור חיים, קבלת fixture הנדסית ו-manifest מכונה. כל הרכיבים המקומיים ברירת-מחדל שלהם היא ללא ספק, ללא רשת וללא כתיבת תוכן גולמי למעקב. הסטטוס אינו מאשר הרצת ספק ואינו מציג תוצאה.

## שערי בדיקה שעברו

| שער | מצב | משמעות |
|---|---|---|
| סכימת שתי הקונפיגורציות | PASS | `VEGO_AI_ON` ו-`VEGO_AI_OFF` עומדות במבנה הקפוא |
| קורפוס ומזהי מקרה | PASS | `cd_airtravel`, `text2uml_airtravel_253b26dc`, ארבעה מקרים זהים |
| ספק, פרמטרים ומגבלות | PASS | אותו זוג מודל/ספק, פרמטרים ומגבלות; execution/network מושבתים |
| שוויון תנאים | PASS | רק תנאי, תזמור, מקורות פרומפט, פלטים ומדד Detector שונים |
| בייסליין OFF | PASS | מסלול ישיר חדש; רשימת מקורות מימוש VEGO ריקה |
| הפרדת reference | PASS | מדיניות runtime-visible ריקה ומסלולי reference מוחרגים |
| זהות ורישום | PASS | מזהי run/event כוללים תנאי ואינם חופפים |
| מחזור חיים ON | PASS | stream תקין מתקבל; stream פגום נדחה fail-closed |
| Detector-v1 | PASS | זמין ל-ON בלבד; OFF הוא `NOT_APPLICABLE` |
| פרטיות | PASS | רק מטא-דאטה בטוח במסמכים; raw content נשאר ignored/private |
| fixture parity | PASS | קבלת fixture הנדסית בלבד; provider/network = 0 |

הטבלה מתארת בדיקות חוזיות מקומיות. היא אינה מתארת פלט AirTravel, איכות מודל, דיוק או השוואת ביצועים.

## מה עדיין חסום

1. אין הרשאה להרצת ספק, ולכן `execution_enabled=false` נשמר בשתי הקונפיגורציות.
2. אין תוצאה מדעית או תצפית production; קבלת fixture אינה מחליפה הרצה.
3. עלות אמיתית וטוקנים מסומנים `NOT_MEASURED_PREPARATION`.
4. Detector-v1 לא הופעל; עבור OFF הוא אינו ישים.
5. נדרשות סקירה ואישור אנושיים נפרדים למחקר 2A, כולל מודל, תקציב, timeout, שימור ונתיב פלט.

## פקודת ההכנה המקומית

הפקודה הבונה את ה-manifest היא:

```text
python scripts/study2_vego_ai_on_off.py --write-manifest
```

היא קוראת קבצי קונפיגורציה tracked בלבד, בודקת hashes של מקורות פרומפט, מפעילה פונקציות fixture בזיכרון ומייצרת מטא-דאטה. היא אינה קוראת את ארבעת מקרי AirTravel, אינה פותחת לקוח מודל ואינה שולחת רשת. אין להריץ פקודה זו כהרצה ניסויית; כל future runner חייב להיות תוספת מורשית ונפרדת.

## חוזה פלט עתידי

אם תאושר הרצה מאוחרת, כל תנאי ייכתב ל-root פרטי נפרד. לכל רשומה יהיו `study_id`, `condition_id`, `run_id`, `case_id`, חותמות זמן, סטטוס השלמה, ספירת קריאות, טוקנים, retries, עלות ו-hash אירועים. ON יכלול את שדות האפיזודה וה-Detector; OFF יכלול `detector_applicability=NOT_APPLICABLE` ולא אפס מלאכותי. חריגה בסכימה, containment, privacy, מכסה או זהות תגרום לכשל סגור.

## החלטת מוכנות

ההחלטה היא **מוכן להרשאה נפרדת** מבחינת מבנה ההכנה בלבד. אין בכך הרשאה, אין בכך התחייבות לתוצאה, ואין בכך אישור לשנות את Study 1. לפני כל ספק אמיתי יש להפיק grant חד-פעמי הקשור ל-manifest ול-commit, ולאשר אותו במפורש.
