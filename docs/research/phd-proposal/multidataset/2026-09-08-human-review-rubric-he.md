# טופס הכנה לבדיקת מומחים — VEGO-AI Study 1

סטטוס: **תבנית בלבד. אין בה דירוגים, דוגמאות אמת או תוצאות אנושיות.**

## יחידת בדיקה

יחידת הבדיקה היא אירוע Q&A אחד, לאחר הסתרת תוכן רגיש. אין לדרג הודעה בודדת
ואין להסיק שהתרעת Detector-v1 היא שגיאה.

## שדות חובה לכל כרטיס

| שדה | ערכים מותרים | משמעות |
| --- | --- | --- |
| מזהה כרטיס | hash-safe ID | אינו כולל טקסט מקור או prompt. |
| מקור ראיה | ARCHIVAL / PROSPECTIVE / ENGINEERING_ONLY | מסווג את הראיה. |
| שלמות מחזור חיים | COMPLETE / INCOMPLETE_TECHNICAL | אירוע לא שלם אינו נכנס למכנה מדעי. |
| תווית Detector-v1 | STRONG_ALERT / WEAK_ALERT / NO_ALERT / NOT_APPLICABLE | תווית דיווח בלבד. |
| החלטת בודק | REVIEW_WORTHY / NOT_REVIEW_WORTHY / INSUFFICIENT_INFORMATION | שיפוט אנושי עצמאי. |
| פעולה מוצעת | verify / clarify / revise-guideline / no-action | אינה מפעילה שינוי אוטומטי. |
| נימוק קצר | טקסט חופשי, ללא פרטים מזהים | מסביר את הבחירה. |

## הוראות לבודק

1. בדוק אם האירוע ראוי לבדיקה אנושית נוספת — לא אם הוא "נכון" או "שגוי".
2. סמן `INSUFFICIENT_INFORMATION` כאשר הכרטיס אינו מאפשר החלטה בטוחה.
3. אל תשתמש בתווית QuRE כדי לקבוע נכונות של Detector-v1. תווית QuRE היא
   איכות דרישה חיצונית, לא אמת־מידה ישירה לצורך בהתערבות אנושית.
4. אל תדרג מקור, guideline, target או מודל. אין מנגנון תיקון אוטומטי.

## כללי הכרעה

- שני בודקים עצמאיים מדרגים כל כרטיס בנפרד.
- מחלוקת עוברת לבורר שלישי; הבורר רואה את שני הנימוקים ללא זהות הבודקים.
- מדווחים הסכמה, אי־הסכמה, ומספר כרטיסים בלתי־מספיקים בנפרד.
- לפני קיום הדירוג: `alert correctness = NOT_MEASURED`,
  `false-positive rate = NOT_MEASURED`, `human benefit = NOT_MEASURED`.
