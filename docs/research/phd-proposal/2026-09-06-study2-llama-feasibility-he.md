# מחקר 2B — רשומת היתכנות מודל Llama

**שאלה נפרדת:** רגישות מודל VEGO-AI תחת תזמור קבוע. **מצב:** `FEASIBILITY_PENDING_REVIEW`; לא הורד מודל, לא הופעלה הסקה ולא נאספו נתונים.

## כלל ההפרדה

מחקר 2B אינו "Codex מול Llama" ואינו חלק מהשוואת `VEGO_AI_ON` מול `VEGO_AI_OFF`. ההשוואה העתידית התקפה, אם תאושר, היא:

`VEGO_AI_ON + GPT-5.6 Luna` **מול** `VEGO_AI_ON + מודל Llama בעל מזהה מדויק`.

היא תחייב הרשמה מוקדמת, תקציב, הרשאה, דוח ומכנים נפרדים. אין לצרף תוצאות Llama לתנאי OFF או לפרש אותן כתוצאה על תזמור.

## דרישות לפני בחירה

1. לקבע revision/commit ו-hash של כל משקל ו-runtime.
2. לתעד חומרה, quantization, זמן טעינה, זמן inference ועלות חשמלית מקומית — בלי להציגם כתועלת מדעית.
3. לבדוק offline את אותה סכימת `structured_uml_review_v1`, parseability, timeout ומוני retries.
4. להוכיח שאין גישה לרשת בזמן הרצה מקומית ושאין נתוני AirTravel יוצאים מה-root המורשה.
5. לקבל אישור רישוי להפצה של קוד, weights, תוצרים או שירות, ולשמור notice/ייחוס כנדרש.
6. להוסיף את המודל כתנאי נפרד בלבד, עם מכסה, תקציב, run IDs ודוח משלו.

## החלטה נוכחית

`Llama` אינו מורד, אינו מופעל ואינו נכלל ב-Study 2A. הרשומה היא מפת היתכנות שמציינת מה ידוע ומה חסר; היא אינה תוצאה, אינה benchmark ואינה בחירת מודל.
