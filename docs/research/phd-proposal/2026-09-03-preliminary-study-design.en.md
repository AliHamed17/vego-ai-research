# Preliminary Study 1 design, for comment before the run: WHEN to escalate to a human in VEGO-AI (Cheers, ParkWise)

**For Iris Reinhartz-Berger and Arnon Sturm. Ali Hamed, 3 September 2026. One study; one question: WHEN to escalate.**

**Question.** In one frozen VEGO-AI run, at which points do signals the pipeline already emits mark where a human judgment could have been requested? Three point sets, kept apart: (a) automatically flagged, (b) disagreeing with existing reference material, (c) marked by three humans. The sets are candidate points only; whether asking would have helped is not scored. Addresses the WHEN clause of SQ1 (when and how should the assessment system request human judgment); the how and expert-burden clauses are not addressed (wording provisional, not supervisor-approved). Direction: bottom-up from the data; literature last. Not asked: how an intervention is carried out, how a user is approached, or whether anything improves.

**Data (course examples, no synthetic data).** Frozen run VEGO-AI/runs/20260614-122150; Cheers (ch), ParkWise (pw); use-case (ucd), class (cd) diagrams: 179 scored rows (46/44/48/41 for ucd_ch/ucd_pw/cd_ch/cd_pw; 14 case ids scored twice), 165 per-case Agent 3 files (45/37/46/37), 27 Agent 4 patterns (8/8/4/7). Stages 1-4 are Agents 1-4: template guidelines, domain guidelines, inspector, classification. Stage 1-3 signals are read from the evaluator outputs in VEGO-AI/eval_output/<setting>/ (local, not tracked); Stage 4 from the run's human layer.

**The run as-is, and the reference material for (b).** Run as-is: its only escalation hook follows Agent 4 (human_review_queue.py): 11 of 27 patterns queued; Low, Undetermined and requires_human_review: 0/27. Agent 2 raised 12 questions to the language advisor (2/1/3/6), none answered in the frozen run; Agents 3-4 raised 0. **The case, (c).** Worked trace, disclosed here, so its marks are post-disclosure: ucd_ch pattern P6 "Customer as actor": models 68114, 68064, 68113, 68059, 68132; strength 12.5%; Agent 4 Occasional, Medium; queued by medium_confidence alone; resolved by placeholder expert_02. Stage 1 fired nothing (8/8 High). Stage 2: none of 27 guidelines names Customer as actor; G2 (certainty 0.9) gives ordering to sales staff. Stage 3: 3 of 5 models carry an Alternative fragment naming Customer as actor (68114, 68064, 68113); 68059's fragments name only a Customer use case (the model itself declares a Customer actor that Agent 3 did not flag); 68132 none. Sheet (about 15 minutes): Iris, Arnon and Ali each mark, before the per-row CSV is opened, the other 7 ucd_ch patterns and their models: ask a human here (yes/no); stage (1-4); intervention type (approve AI decision, accept valid alternative, propose guideline update, as in the resolved queue); for each yes, the guideline, fragment or pattern id it would touch. Injected intervention, in the form raised on the call (suppose at this point we intervene in this way): on P6 we add the missing Stage 2 guideline "Customer is an actor who places orders" by hand, re-read the five models' Stage 3 fragments and the P6 classification against it, and record what changes (fragments that stop being Alternative; whether P6 remains a deviation). No agent is re-run; no quality is judged.

**Measures (descriptive; numerator / denominator, counts only).** m1: flagged points per stage, as tabled. m2, Stages 1-2: each unassigned or low-certainty cluster is matched by one marker, by text, to at most one missed reference item; m2 = matched pairs / missed reference items. m3: marks on the same guideline, fragment or pattern as a signal (text match) / marks; marks with no signal, listed. m4: pairwise agreement (Ali-Iris, Ali-Arnon, Iris-Arnon), each over rows both marked. m5, Agent 2 versus Agent 3, is an earliest-stage count, not a cost argument: per ucd_ch pattern, the earliest stage with a signal on the same point; the Stage 2 signal for guideline-anchored patterns is best-run mapping certainty < 0.8 (P1-P3 rest on G20, G22, G18 at 0.8, 0.8, 0.7, so it fires for P3 only); P4-P8 by fragment-text matching in the 45 case files, manual where needed. P6: Stage 3, 3 of 5 models. No stage is ranked; m5 reports only where the earliest signal sits per pattern.

**Not claimed.** No accuracy, improvement, effort or generalization statement; asking a human may also harm or change nothing. No independent expert label exists for any of the 27 Agent 4 classifications (EXP-005 label gate: 0 of 24 candidate rows labelled). Our marks are not expert ground truth. Literature, positioning only: predictive confidence can degrade under shift (Ovadia et al. 2019), so Stage 1-3 signals are read beside Agent 4 confidence, not ranked against it; the human-feedback branch of the human-agent survey (Zou et al. 2026); learning-to-defer as framing (Mozannar and Sontag 2020); the system itself (Reinhartz-Berger, Bragilovski and Sturm 2026).
