# Governed Knowledge Operating Model

VEGO-AI remains the canonical project record. Codex, Claude, and ChatGPT consume a cited local context packet generated from approved records. Raw exports, private transcripts, screenshots, credentials, and Drive identifiers remain in ignored restricted storage.

Collection is read-only. Every record carries a source reference, SHA-256, classification, and review state. A sync command first creates a dry-run manifest; writes require an explicit approval and reject restricted or secret content.

`codecium` is intentionally disabled. Enable it only after recording the vendor, workspace alias, authentication method, retention policy, access scope, and the exact approved record classes.
